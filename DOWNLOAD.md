# Как скачать клип и проект

Эта инструкция предназначена для просмотра проекта на GitHub после загрузки ветки `video-download`.

## Посмотреть клип

1. Откройте `output/112_music_video_final.mp4` для Full HD или
   `output/112_music_video_view_720p.mp4` для компактной версии.
2. Нажмите кнопку скачивания файла на странице GitHub («Download raw file» / стрелка вниз).
3. Откройте скачанный MP4 видеоплеером на телефоне или компьютере.

Обе версии содержат весь клип, 4 минуты 33,12 секунды. Full HD — 1920 × 1080,
компактная версия — 1280 × 720. Видео для передачи дополнительно сжато;
музыка Full HD скопирована из готового мастер-файла без повторного кодирования.

## Скачать весь проект

На странице репозитория выберите ветку `video-download`, затем **Code → Download ZIP**.
Распакуйте архив. Внутри находятся все 52 отдельных PNG, исходная песня,
раскадровка, готовые видео и программы повторной сборки.

Команды сборки и проверки описаны в README.md. Для просмотра готового MP4
устанавливать Python или FFmpeg не требуется.

В облачной рабочей папке дополнительно сохранён мастер-файл с меньшим сжатием.
В этой ветке GitHub файл `output/112_music_video_final.mp4` — его Full HD копия,
подготовленная для передачи с учётом ограничения GitHub на размер одного файла.

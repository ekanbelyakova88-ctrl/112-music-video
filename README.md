# 112-music-video — «112. Мы на связи»

Художественный музыкальный клип к десятилетию службы 112 Владимирской области.
52 отдельно сгенерированных фотографических кадра, движение камеры, мягкие переходы и русские титры.
Вымышленные персонажи и ситуации; это не хроника реальных происшествий.

## Результат

`output/112_music_video_final.mp4`: 1920 × 1080, 16:9, 25 кадров/с, H.264 / AAC, 273,12 секунды.
В клипе использована предоставленная песня целиком, без изменения скорости и высоты голоса.
Итоговый звук перекодируется в AAC; исходный MP3 сохранён без изменения байтов.

## Структура

- `assets/audio/song.mp3` — оригинальная песня.
- `assets/images/scene_001.png` … `scene_052.png` — отдельные кадры 1920 × 1080, без коллажей.
- `assets/video/` — место для дополнительных видеосцен; сейчас не используются.
- `storyboard/scenes.json` — описания и индивидуальные запросы генерации.
- `storyboard/timeline.json` — точная монтажная шкала в кадрах и секундах.
- `storyboard/README.md` — удобная таблица раскадровки.
- `storyboard/prompts.md` — все индивидуальные промпты.
- `storyboard/audio_analysis.json` — измеренные звуковые акценты.
- `scripts/` — подготовка, импорт кадров, монтаж и проверка.
- `output/validation.json` — результаты проверки готового файла.
- `output/.render/` — воспроизводимый промежуточный кэш, в архив проекта не входит.

## Повторная сборка

Нужны Python 3.12+, FFmpeg с libx264, AAC, libass, zoompan и xfade, а также шрифт Noto Sans с кириллицей.
В подготовленной облачной среде инструменты и библиотеки уже установлены.
Для новой машины: установите FFmpeg и `fonts-noto-core` системным пакетным менеджером,
затем создайте виртуальное окружение и установите Python-зависимости:

```sh
cd /workspace/112-music-video
python -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python scripts/prepare_storyboard.py
.venv/bin/python scripts/build_video.py --workers 2 --preset fast
.venv/bin/python scripts/validate_video.py
```

Для текущей среды можно использовать `python` вместо `.venv/bin/python`.
Запускать команды нужно из корня проекта. Web-сервер, ключи API и внешние службы для сборки не нужны.
Используйте существующий checkout: облачная задача уже изолирована, новый Git worktree не требуется.

Сборщик проверяет наличие **всех** настоящих изображений. Заглушек и автоматического дублирования кадров нет.
Кэш привязан к содержимому изображений и параметрам: изменённые кадры будут пересобраны.
52 клипа сначала получают плавное движение камеры; внутри семи глав используются перекрёстные наплывы,
между главами — монтажные склейки. Затем накладываются титры и оригинальная музыка.

## Изображения и замена кадров

Кадры создавались отдельными запросами встроенным инструментом `image_gen`, не коллажами.
Исходный размер генерации нормализуется FFmpeg до 1920 × 1080 с минимальным центральным кадрированием.
Встроенный инструмент доступен ассистенту и не является локальным Python API.
Для повторной генерации используйте индивидуальные промпты из `storyboard/prompts.md`
в доступном вам генераторе, каждый запрос отдельно. Сохраните результаты как `scene_NNN.png` или `.jpg`,
затем импортируйте:

```sh
python scripts/import_images.py /path/to/separate/generated/images --replace
python scripts/build_video.py
python scripts/validate_video.py
```

Кадры и промпты уже включены в проект: повторная генерация для сборки не требуется.
Новый результат генератора может отличаться, поэтому после замены необходим визуальный просмотр.

## Художественные решения и проверка

Диспетчерская построена по текстовому описанию заказчика: деревянные перегородки, обычные мониторы,
телефоны и лёгкие офисные гарнитуры. В исходных материалах был юбилейный постер,
но не фотографии настоящего рабочего помещения. Реальные лица сотрудников не копировались.
Надписи добавлены средствами монтажа; служебные экраны и бумаги не содержат реальных данных.
Автомобилей отдельной выездной службы 112 не предусмотрено.

Движение в клипе — монтажная анимация фотографических кадров, а не сгенерированная движущаяся съёмка.
Привязка к музыке выполнена по измеренным атакам звука; расшифровка текста песни не выполнялась.
География и профессиональные действия изображены художественно и не являются инструкцией.

`validate_video.py` проверяет все 52 файла, размер, уникальность файлов, кодеки, число кадров,
продолжительность, полное декодирование видео, сходство всей звуковой дорожки с оригиналом
и отдельно синхронизацию звука в начале, середине и конце песни.
Визуальные особенности (лица, руки, техника, отсутствие коллажей) проверяются отдельным просмотром.
